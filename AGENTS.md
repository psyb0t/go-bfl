# go-bfl

Unofficial Go client for the Black Forest Labs FLUX API, generated from its public OpenAPI document. For using the client from an agent, read [.agents/skills/go-bfl/SKILL.md](.agents/skills/go-bfl/SKILL.md). This file covers changing the code.

## Architecture

One generated package, `bfl`, at the module root, driven by `gen.go`:

`scripts/fetch-spec.sh` downloads `https://api.bfl.ai/openapi.json` to `api/openapi.json`, then `scripts/patch-spec.sh` writes `api/openapi.fixed.json`, then oapi-codegen with `config.yaml` writes `client.gen.go`.

## Stack

- Go 1.26.9.
- oapi-codegen v2.8.0, pinned as a `tool` dependency in `go.mod`.
- Runtime: `github.com/oapi-codegen/runtime`.

## Layout

- `gen.go`, `config.yaml`, `client.gen.go`: the package.
- `client_test.go`, `example_test.go`: tests, including the README example.
- `scripts/`: spec download, schema conversion, lint and security scans.
- `api/`: downloaded and converted specs, gitignored.
- `vendor/`: distributed dependencies, regenerated by `make dep`.

## Dev workflow

Everything runs in the `Dockerfile.dev` image. You need Docker and Make.

```bash
make dep       # go mod tidy + go mod vendor
make generate  # download the spec and regenerate
make lint      # shellcheck, shfmt, go fix, golangci-lint
make test      # go test -race
make sec       # gitleaks, govulncheck, semgrep
```

## Project-specific landmines

- The source is OpenAPI 3.1.0. The patch converts nullable `anyOf` branches, inlines singleton unions, converts `const` to enum and represents positional keyframe tuples as arrays of untyped JSON values. Tuple positions need caller validation. Genuine unions stay unions.
- Keep the `number` to `float64` mapping for costs, credits and progress.
- Auth is the `x-key` header. `/v1/get_result` has no auth requirement in the spec.
- Submissions return a union. Use `AsAsyncResponse()` for polling or `AsAsyncWebhookResponse()` for webhook mode. A successful decode does not validate required fields; check `Id` and `PollingUrl`.
- Poll with the task ID. `Pending`, `Reasoning` and `Generating` are nonterminal. `Ready` has a result; moderation, task-not-found, no-card and error states are terminal failures. Result data is untyped JSON.
- Method names come directly from long operation IDs. Check generated names before using them in docs.
- Generation downloads the current spec and may change the exported client. Review generated changes.
- Security scanning handles source archives without Git history; it still scans all distributed source and vendor files.
- `.github/workflows/regen.yml` regenerates the client every day and releases the result. When the checks fail, Claude edits the repository to fix them, but a fix may not touch the paths listed under `fix_protected_paths` in that workflow: the workflows, the Makefile, `AGENTS.md`, `.agents/rules/`, the lint, security and spec download scripts and their configs. A problem that needs a change there fails the run and needs a manual fix.
